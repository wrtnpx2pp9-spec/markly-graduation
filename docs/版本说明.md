# 教学版本说明

版本：`1.0.0-education.1`。本版本是 Markly 的独立教学快照，用于本机学习、演示和二次开发。

## 整理范围

- 保留账号、协商、计划、每日安排、执行审核、复盘、归档与历史的核心代码，以及相关自动化测试。
- 使用独立仓库和清洁的起始历史，避免将原项目 Git 历史、内部部署过程和本地运行产物带入教学分发。
- 提供中文入门说明、代码阅读路线、数据模型、演示与答辩准备及二次开发选题。
- 提供独立演示数据库与随机演示账号流程；凭据只保留在被忽略的本机文件中。
- 只发布配置模板，不包含已配置的环境变量、真实业务数据库、真实用户、外部通道凭据、日志或浏览器产物。

## 运行边界

教学环境推荐 Node.js 24，最低支持 Node.js 22.19.0。使用单实例 SQLite 和原生前端，不要求安装单独数据库服务器。

常规启动从空白数据库开始；演示模式使用独立的 `demo-data/app.db`。AI、微信和外部通知默认关闭，人工计划流程可独立完成。可选模块保留用于阅读和后续研究，接入真实服务需要自行核验授权、数据用途、凭据、费用及供应商限制。

本版本没有因为重新打包而自动实现所有安全建议。账号会话、外部请求、管理员数据访问、浏览器草稿和备份恢复等仍应按实际部署环境评估。测试通过不代表经过完整渗透测试、法规认证或真实通道验收。

## 测试说明

本仓库提供 `npm test` 和完整 `npm run release:check`。后者包括隔离数据库、运维与浏览器流程，结果保存在本机 `output/release/`。`--skip-ui` 不满足完整发布门槛。

应以本次实际运行报告和具体环境说明验证结果，不沿用原项目的生产部署、真实账号或内部报告作为本教学仓库的通过证据。模型、通知替身和临时数据库测试，只证明相应受控场景。

## 来源和后续维护

本教学版由同作者的 Markly 项目整理。原项目仓库为 <https://github.com/wrtnpx2pp9-spec/markly>，可能受访问权限限制；学习者无需访问该仓库即可运行本教学版本。通用版权说明和 MIT 条款见根目录 [LICENSE](../LICENSE)。

版本号用于区分教学分发与原项目开发进度。二次开发时记录所依据的标签和提交，保留来源与许可，并说明新增内容。后续教学版本应单独更新版本、测试和发行说明，不自动包含真实实例的数据或配置。
